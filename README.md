# Forma Living

A responsive interior design business website built with HTML, CSS, and JavaScript.

## Features

- Responsive design for mobile and desktop
- Interior design services section
- Mobile navigation menu
- Contact enquiry form demo
- Modern, minimal styling

## How to run

1. Download the project files.
2. Open the folder in VS Code.
3. Open `index.html` in your browser.
4. For easier development, use the Live Server extension.

## Main files

- `index.html` — website structure
- `styles.css` — design and responsive layout
- `app.js` — navigation and form interactions

## Important

Forma Living is a fictional concept brand. Replace placeholder contact details and use approved images before deploying a real business website.
